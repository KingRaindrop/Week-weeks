# 日程模式自适应时间轴（2026-11-16）

> 发布说明：本文记录历史验证。`artifacts/`、`build/` 下的日志、截图、备份与预览 APK 等本地产物未入库，所列路径不是下载链接；复现命令中的环境路径和设备标识需替换为本机配置。

入口：设置 → 模式选择 → 日程模式，然后选择「周视图」。设置日程的开始、结束时间后，日程块按开始时间定位，并随时长调整高度；编辑保存后立即更新，保留当前浏览日期及周视图/列表布局。

## 展示规则

- 每小时使用相同纵向比例；30、60、120 分钟的时间跨度按 1:2:4 显示，卡片之间保留小间距。
- 时间轴根据当前周最早、最晚的日程自动向整点扩展。
- 短于 30 分钟或未设置结束时间的日程，保留相当于 30 分钟的最小显示高度，方便点击；不改写真实时长、结束状态或提醒。
- 接近午夜的短日程保持真实起点，卡片延伸到 24:00 下方的留白；不显示超过 24:00 的时间刻度。
- 重叠日程在宽度足够时并排；空间不足时显示「N 项日程」，点击后可选择其中任意日程。选择器支持旋转恢复与取消。
- 列表、课表模式和综合模式沿用原有布局。仍尊重单条日程「显示在课表」开关。
- 极窄窗口和大字体下，卡片标题可能以省略号显示；点击可查看完整内容，辅助功能描述保留完整时间、标题。

## 实现范围

新增纯 Java 布局规则 `AgendaTimelineLayout.java`，在 `PastelTimetableView.java` 接入周时间轴、最小高度、重叠分组及文字高度适配。`MainActivity.java` 绑定真实结束分钟、处理重叠选择并保留保存后的视图。新增三语时间轴资源，更新三语日程模式提示。

相对本轮备份，源数据存储、提醒和 Manifest 没有修改。此前未提交修改及安装包保留；本轮源码快照位于 `artifacts/backups/agenda-timeline-20261116/src/`。
