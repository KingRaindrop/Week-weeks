# 设置中的显示模式（2026-11-16）

> 发布说明：本文记录历史验证。`artifacts/`、`build/` 下的日志、截图、备份与预览 APK 等本地产物未入库，所列路径不是下载链接；复现命令中的环境路径和设备标识需替换为本机配置。

入口：设置 → 显示内容 → 模式选择。

| 模式 | 显示内容 |
| --- | --- |
| 课表模式 | 课程；隐藏个人日程及新增日程入口 |
| 日程模式 | 个人日程；隐藏课程概览、倒计时、导入快捷按钮和课程节次网格 |
| 综合模式 | 课程和个人日程；未设置时默认使用此模式，保留升级前体验 |

模式同时作用于周视图、列表及“我的”页，不改变当前标签、布局或浏览日期。日程周视图提供逐日新增按钮；课表模式下“我的”页保留设置入口及说明。主视图继续尊重单条日程“显示在课表”开关，“我的”在日程/综合模式仍能管理所有个人日程。

选择后点击“确定”才保存；取消不应用，旋转保留尚未确认的选择。保存使用现有偏好事务；写盘失败时保持原模式并提示重试。未知或错误类型的旧偏好回退综合模式。模式只用于展示，不修改课程/日程源数据、提醒开关或提醒计划。切回对应模式即可恢复内容。

本次生产修改为 `DisplayMode.java`、`MainActivity.java`、`PastelTimetableView.java`、`PastelCourseSheet.java` 及六份三语资源文件。相对本次快照，存储、提醒和 Manifest 未修改。保留所有此前未提交更改及旧安装包；快照位于 `artifacts/backups/display-modes-20261116/src/`。
