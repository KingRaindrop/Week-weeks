# 周课表怎么导入

在「导入课表」选择 XLSX、CSV、TSV 或 TXT 文件，也可以从电子表格复制一块区域，选择「粘贴文本课表」。请连同**星期表头和节次列**一起复制。应用先显示预览，确认后才保存。原有的[每行一门课列表](templates/README.md)仍然可用。

下面这三行可以直接复制到粘贴框试用（逗号分列，课程均为虚构示例）：

```csv
节次,周三,周一,周五
1-2,物理实验,,设计基础/教室：A/101
3,,写作,
```

预览应有三门课：周三第 1–2 节物理实验、周五第 1–2 节设计基础（教室 `A/101`）、周一第 3 节写作。识别按星期名称和写出的节次进行，空格子表示没有课。星期不必从周一开始；节次可以跳过，但必须从小到大，不能重复或重叠。

- **表头**：第一格写「节次」「節次」或 `Period`，也可以留空；右侧至少有两个不同的星期，例如 `周一`、`週五`、`Wed.`。不能仅用数字或颜色代表星期。表头上方可以另放一行如「秋季课程表」的标题。
- **连堂课**：XLSX 可在同一个星期列内纵向合并，课程放在合并区域的第一格，所跨各行要有连续的节次；横向跨星期的合并无法确定是哪天。CSV、TSV 及复制的文字不保留 Excel 的合并信息，请明确写成 `1-2`，不要指望下一格空白自动延长上一门课。如同一时段各天的连堂情况不同，优先直接导入 XLSX。
- **格子里的信息**：第一行是课名，之后可写 `周次：1-16周`、`教室：A/101`、`教师：陈老师`，也可同一行用 `/` 接带标签的字段。留空周次表示每周。支持繁体和 `Weeks:`、`Room:`、`Teacher:` 标签。
- **单双周两门课**：在同一个单元格中，像下面这样将两门课隔一个空行。CSV、TSV 中含换行的格子需要用双引号包住；Excel 单元格内直接换行即可。

```text
物理实验
周次：1-16周单周

设计基础
周次：1-16周双周
```

如周课表提示 `C3`，请检查第三列的对应行；XLSX 会给出工作表名，合并错误会显示如 `B2:C2` 的范围。粘贴或 CSV 中的行号按原文计算，含换行的引号字段算在原始行数里。发现错误的周课表不会进入可保存的预览。

旧 `.xls` 请先另存 XLSX 或 CSV；含公式的工作表请先导出为纯值。文字型 PDF 走另一套解析流程：在结构可识别时支持如 `週３`、`第０１－０２節`、`１－８週（單週）` 和 `／教室：Ａ/101／授課教師：…`。扫描 PDF、图片和只靠空格对齐的表格不在这次支持范围。
