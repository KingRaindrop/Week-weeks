# PDF 与常见课表文件解析增强

> 当前版本已支持带星期表头及节次的周课表与同星期纵向合并，见[周课表导入说明](IMPORT-PARSERS-20261119.md)。下文是当时的格式边界与验证记录。

> 发布说明：本文记录历史验证。`artifacts/`、`build/` 下的日志、截图、备份与预览 APK 等本地产物未入库，所列路径不是下载链接；复现命令中的环境路径和设备标识需替换为本机配置。

## 支持范围

文件选择器现在接受 PDF、XLSX、CSV、TSV、TXT，复用原有后台解析、生命周期恢复、节次补全、导入预览和确认提交流程。文件仍限制为 5 MiB，未修改加密存储格式、课程配色或提醒逻辑。

| 文件 | 识别方式 | 重要边界 |
| --- | --- | --- |
| PDF | 文字型教务课表，按页读取内容和字体，结合星期标题与节次/周次文本识别 | 非通用 PDF 渲染器；扫描件不做 OCR；不承诺任意表格版式 |
| CSV | 逗号分隔、带引号字段、转义双引号和跨行字段 | 包含逗号的周次/教室必须按 CSV 规则加引号 |
| TSV / TXT | Tab、半角或全角竖线分隔，每行一门课；TSV 支持引号 | 不会猜测用空格排版的网格，也不会把时刻误当节次 |
| XLSX | 可见工作表中的列表，每行一门课；支持共享字符串、内联富文本、数值节次和稀疏行列 | 合并单元格、公式、错误/布尔单元格拒绝；不计算公式；隐藏工作表不导入 |

旧版二进制 XLS 暂不支持，应先另存为 XLSX 或 CSV。DOC/DOCX、HTML、ICS 和图片不是本轮支持格式。

## 列表格式与模板

建议使用 [XLSX 模板](<templates/timetable-list-template.xlsx>) 或 [CSV 模板](<templates/timetable-list-template.csv>)，表头为：

```text
课程名称,星期,开始节次,结束节次,上课周,教室,教师
高等数学,周一,1,2,1-16周,教学楼A101,张老师
```

也支持原来的无表头顺序：

```text
课程名 | 星期 | 节次 | 上课周 | 地点 | 老师
高等数学 | 周一 | 1-2 | 1-16周 | A101 | 张老师
```

- 常见简体、繁体、英文表头可以重排；课程、星期、节次是必需项。节次可由“开始节次/结束节次”两列提供。
- 已识别表头中的未知列作为元数据忽略；重复、缺失或相互冲突的字段会报错，不会猜测。
- 支持周一至周日、星期/礼拜/繁体写法、1–7、Mon/Monday 等明确星期名。不接受 Mondayish 等前缀相似词。
- 周次沿用原有严格规则，增加繁体及 `weeks`、`odd`、`even` 等词的规范化；空周次表示每周。
- 文本文件支持 UTF-8（含 BOM）、带 BOM 的 UTF-16 LE/BE；无 BOM 时 UTF-8 严格解码失败后尝试 GB18030，失败则提示另存 UTF-8。
- 文本和每张工作表的总内容预算为 20,000 字符（工作表额外计入行/单元格开销），单字段 60 字符，节次与周次范围沿用应用限制。
- CSV/TSV/XLSX 任意一行报错，本次文件不会进入可提交的部分成功状态；错误提示带行号，XLSX 还带工作表名。修正后重新导入。

## PDF 解析重点

- 使用页树顺序和页内容数组，分开处理每页，避免将字体映射或元数据流当成课程文本。
- 绑定当前字体资源的 ToUnicode 映射，支持 bfchar、bfrange（连续映射和数组映射）；无映射字体保留原有严格编码识别逻辑。
- 支持 literal/hex 的 Tj/TJ、相对文字定位、换行及图形变换，减少导出方式不同造成的文字错位。
- 优先从星期标题校准列/行位置；无法校准时保留旧课表样式坐标兼容，并在仅调试版的解析日志中标记回退。
- 保留课程名称跨片段、周次换行、单双周、附带时间剥离、地点/教师提取等原逻辑。
- 不计算字形宽度、连续 Tj 的隐式光标推进及 TJ 字距；无 ToUnicode 字体仍使用原有编码启发式。不同学校的字体、任意网格、复杂分页、增量修订和非零 generation 并非完整 PDF 标准覆盖。
- PDF 仍可能因没有足够结构线索而无法识别，导入预览不能替代对原文件的人工核对。

## 安全与失败行为

- XLSX：256 个 ZIP 条目、总展开 16 MiB、单个相关 XML 2 MiB、最多 2,000 源行及 64 列；不将压缩包条目解压到磁盘。
- XML 必须严格 UTF-8，解析已验证字符源，拒绝 DTD/ENTITY/NUL 并关闭外部实体；防止声明编码绕过。
- 校验源行号、行顺序、单元格完整地址与所属行；不容忍错位/畸形引用。
- XLSX 不执行宏、不计算公式、不访问外部工作簿；含公式或合并结构时提示导出纯值列表。
- PDF 内容展开量、对象、递归、字体映射等均有限额；加密 PDF、压缩对象流、需要 Form XObject 的文本及未知解码过滤器明确失败，不静默猜测。
- PDF 超过课程数上限改为明确拒绝，取代旧的截断行为。
- 解析诊断日志仅在 debug 输出；release/pastel 不记录课程名、地点与教师等敏感内容。
