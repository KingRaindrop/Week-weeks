# Week weeks 界面与交互说明

## 默认界面与构建

- 应用对外统一为 **Week weeks**，不再区分“原版／清新版”。最新界面现为 debug、release 和 pastel 三种构建的默认界面。
- 正式包名为 `com.weekweeks.app`，构建命令 `gradlew.bat assembleRelease`，使用已有正式签名配置及发布优化。
- `pastel` 仅作为内部兼容测试入口保留：`gradlew.bat assemblePastel`，包名 `com.weekweeks.app.pastel`，使用本地 debug 签名，不作为独立产品版本。
- 两个包使用相同界面，但签名、构建优化与数据目录不同；互相独立安装，不自动复制数据，也不卸载或清空已有应用。
- 旧界面代码暂保留，默认构建不再启用。`PASTEL_UI`、`Pastel*` 类名及本文档文件名仅为内部实现标识，不是产品版本名。
- Git 分支 `ui/pastel-university` 暂保留，未提交代码。
- 下方设计说明适用于当前默认界面；历史测试记录中的“原版／清新版”按当时构建含义理解，不代表目前仍有两套对外版本。
- 2026-11-09 全面更名后使用新的应用身份：新包名首次启动为空数据、默认设置，不自动迁移旧应用；旧版应用、课程、日程、设置及提醒仍保留。本轮不会卸载旧应用。新应用偏好文件为 `week_weeks`，存储密钥前缀为 `week_weeks_`，提醒内部 URI 为 `weekweeks://reminder/…`。

## 设计与交互

原生 Android 视图实现，不是图片或 WebView：浅灰蓝底色、深蓝渐变当前课程卡、黄色状态标签、书本插画、珊瑚红视图切换、马卡龙周课表、公告与固定底部导航。

「设置 → 外观 → 界面色调」对整个界面生效（`PastelAccent`）：主色用于按钮、选中的分段与底栏、今日表头、时间线、输入框焦点和光标；当前课程卡渐变、图标按钮底色、分段轨道、提示条和书本插画按所选色相重新着色。界面色调扩展为16种：蓝色、青绿、绿色、紫色、橙色、红色、靛青、珊瑚、暗夜、玫瑰花园、湖光、日落霞光、森林低语、海风、薰衣草梦、杏茶时光。旧索引0–7及颜色保留，所有默认构建首次安装均默认珊瑚；已保存的色调不覆盖。保留的旧界面代码与当前界面共用16色预设（`UiAccentPalette`）。新增8色为柔和的亮／暗成对配色，亮色对白、暗色对深底的对比度至少4.5；“暗夜”是石板蓝色调，不会强制切换明暗模式。色卡按当前主题显示，勾号自动使用可读文字色。选择器采用等宽四列、两行名称、有界纵向滚动，小屏或大字体时改三列；确定才保存，取消不改变设置。课程块颜色仍取各课程自己的颜色，不被界面色调覆盖。

- 16色色调验证：pastel/release 构建成功，93 项单元测试、65 项提醒回归检查全部通过，lint 无错误或警告；MuMu 已覆盖安装。界面层级确认16个色卡与确认／取消按钮可访问，实际切换玫瑰花园并重启后仍选中；临时选择薰衣草梦再取消，仍保留玫瑰花园。截图像素确认亮／暗主色分别为 `#A94F70`／`#F0ABC3`，三条“数据结构”的课程背景不受界面色调影响。测试结束恢复原蓝色与深色模式。

- 周一至周日等宽展示，支持单节和跨节课程。
- 首次安装默认十一节时间（与原版一致）：08:00–08:45、08:55–09:40、10:00–10:45、10:55–11:40、14:30–15:15、15:25–16:10、16:20–17:05、17:15–18:00、19:30–20:15、20:25–21:10、21:20–22:05。已保存的自定义节次不会被覆盖；可在「设置 → 课程节次设置 → 恢复默认 1-11 节」改用这套时间。
- 现有自定义节次继续按真实数据渲染，不强制截成八节。
- 防误触：点按课程只弹出只读详情卡（时间、上课周、地点、老师），卡片底部可点「编辑课程」；长按课程（带触感反馈）直接进入编辑。空白格点按只提示「长按空白格添加课程」，长按才创建该星期、该节次的课程。
- 编辑与添加使用清新风格底部弹层（`PastelCourseSheet`）：星期胶囊、开始／结束节次胶囊（分别显示开始、结束时刻）、节次时间摘要、上课周快捷选项（全学期／单周／双周／临时从本周起）、地点与老师并排、颜色色块。校验与冲突错误在弹层内联显示；有未保存修改时关闭需确认；删除按钮与保存分开并需二次确认。旧编辑表单代码暂保留，但默认构建统一使用当前底部弹层。
- 导入按钮先弹出选择：「导入 PDF 课表」或「粘贴文本课表」。PDF 样式不同导致识别失败时，可以把课表整理成每行一门课的文本粘贴导入，格式为 `课程名 | 星期 | 节次 | 上课周 | 地点 | 老师`（也可用 Tab 分隔，便于从表格复制；后三项可留空）。弹层内有示例、「填入示例」「复制示例」「从剪贴板粘贴」。解析由纯 Java 的 `TextTimetableParser` 完成，逐行报错并标出行号；只要有一行有误就不导入，避免半份课表。识别结果与 PDF 导入共用同一个预览确认、节次不足检查和去重合并流程。设置面板里也有同名入口。
- 通知点开后的上课提醒弹窗只接受 App 自己发出的通知：通知里带一个每台设备随机生成、只存在 App 私有存储里的令牌，主界面校验一致才显示弹窗。别的 App 带参数启动课表只会正常打开课表，不会弹出伪造的提醒。
- 保留教学周预览、上一周、下一周、校历选择和返回本周。
- 在小屏幕上优先保证课程字号可读，课表主体允许纵向滚动；不会为了强塞整屏而压扁课程块。
- 当前课程、下一节课程、状态栏和时间线使用真实数据与系统时间，不固定成设计稿示例。
- 底部为「课表／日程／我的」三栏等宽导航。按用户最新要求，已移除成绩入口、弹窗与统计图标。在主界面左右滑动可依次切换这三栏（左滑到下一栏，右滑回上一栏，两端不循环）；以横向为主且超过 72dp 才算切换，纵向滚动和点按不受影响，弹层内的滑动不会切换。
- 自定义日程（`PersonalEvent`）：一次性的个人安排，如「9月24日 10:00 去图书馆」。
  - 「日程」列表顶部有「＋ 添加日程」。日程只在它的日期所在的那一周出现，与当周课程按日期和开始时间混排，每天标注具体日期。日程不进入周视图格子。
  - 「我的」是独立的整页标签（不再是底部弹层），列出全部日程（待办在前、已结束的变暗在后）、添加入口和「设置」入口。日程详情和编辑弹层叠在这一页上，关闭后直接回到这一页，不再重新弹出；在「我的」添加或修改日程后停留在本页并立即刷新列表。按返回键先回到「课表」，再按才退出。界面重建后仍停在「我的」。
  - 字段：标题、日期、开始时间为必填；结束时间、地点、备注可选。日期可选今天、明天、后天或系统日期选择器；时间可写 10、10:00、10点半、1030。
  - 提醒：不提醒、开始时、提前 10/30 分钟、1 小时、1 天，或自定义提前 N 分钟（最多 7 天）。与课程提醒共用排程、开机恢复和弹窗令牌，受同一个「提醒通知」总开关控制；通知与打开后的弹窗按实际开始/结束时间计算状态，旧通知缺少时间戳时只显示中性提醒文案。
  - 点按日程查看详情，可编辑或删除（删除需确认）；有未保存修改时关闭需确认。日程加密单独保存，最多 300 条；「删除当前配置」不会删除日程。
- 列表和「已上完」变暗按实际日期判断先后。
- 教学周固定为周一至周日：开学日所在的那一周就是第 1 周（周二开学则 8.31 周一–9.6 周日为第 1 周；周日开学则当天是第 1 周，次日周一进入第 2 周）。开学日之前、散学日之后的日子不排课也不提醒。
- 空课表不向持久化数据库注入示例课程，避免污染用户数据。
- 兼容深色主题、系统状态栏及底部安全区；内容较多时纵向滚动，底部导航固定。
