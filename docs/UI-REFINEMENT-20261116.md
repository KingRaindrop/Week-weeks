# 界面与设置体验优化（2026-11-16）

本轮完成此前确认的八项优化，覆盖日程视图、设置连续操作、语义配色和时间编辑反馈。

| 需求 | 最终行为 | 验证 |
| --- | --- | --- |

| 设置分组 | 显示、课表、提醒、时间、外观、数据共用组容器；名称与当前值同行，窄屏/大字体改为上下排列；解释放在组下 | 当前值、完整文字、宽屏首次测量和窄屏组件检查通过 |

| 语义配色 | 单独定义背景、表面、次级文字、强调色、强调色上文字及错误色；课程分类色继续独立 | 22 组强调色的角色独立性和文字对比度单测通过；深浅主题设备检查通过 |
| 时间编辑反馈 | 实时显示时间范围、时长、未设结束状态；就近提示无效时间及先后顺序错误 | 时/分组合、无结束、非法输入、纠正错误、日期切换和旋转恢复均通过；输入不被自动改写，保存前不写入数据 |

设置里的提醒开关还会立即同步上方状态值及无障碍描述，返回应用时重新读取提醒状态。
